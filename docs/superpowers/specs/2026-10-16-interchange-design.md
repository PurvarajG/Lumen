# Interchange design

This follows the working native foundation. The user authorized autonomous design decisions. Prioritize practical reuse of shows without claiming fidelity unsupported by evidence.

Add an independent Rust `lumen-interchange` crate consuming lumen-core. It imports plain text, OpenLyrics XML and an explicitly experimental ProPresenter 21.4 text extraction path. It returns a Document plus warnings; it never modifies source files or writes ProPresenter files. The GUI inserts successful imports into library/playlist and presents limitations to the operator. All parser work runs off the UI thread.

OpenLyrics support follows the primary specification at https://docs.openlyrics.org/en/latest/dataformat.html, fetched 2026-10-16. One verse becomes a slide, lines/br preserve line breaks, verseOrder repeats/reorders named verses, title supplies document name, XML escaping is preserved. Chord/comment markup is excluded from visible lyrics. Reject missing referenced verses rather than silently dropping them. Export emits original/user-authored slide text with valid XML, distinct verse names and order. Metadata/layout outside this subset is not round-tripped.

ProPresenter extraction is grounded only in the owned two-slide fixture documented in docs/research/propresenter-owned-fixture.md. Parse protobuf wire framing with bounded length/field count/depth; top-level field 3 supplies the observed title and repeated field 13 preserves the observed cue order. Extract RTF from the empirical nested path 13.* / 10 / 23 / 2 / 1 / 1 / 1 / 13 / 5. Use a tested Rust RTF parser with JS bindings disabled and input limits. Preserve multiple recognized text payloads in one cue in order. Unknown cue structures produce a visible warning and an empty cue, or a clear unsupported-document error if no recognized slide structure exists. Do not treat arbitrary recursively parseable bytes as established slide fields. UUIDs are regenerated for the independent project. Media, exact formatting, layers, actions and round-trip .pro writing are outside this importer.

Input cap is 16MiB with a bounded actual read, wire nesting <=32, total wire fields <=100000, individual RTF payload <=1MiB, XML DTD/entity resolution disabled. Malformed/truncated tags, varint overflow, length overflow, unsupported wire groups and invalid UTF-8 at required string fields return errors. No parser convenience API that unwraps user input. No network or subprocess requirement for imports.

Verification includes synthetic valid/malformed protobuf fixtures; the actual owned original reference fixture as a local manual check; RTF escaped braces/backslashes, Unicode and paragraph breaks; OpenLyrics namespaced XML and repeated verse order; XML escaping export/re-import; empty/oversized input and unknown format errors. Tests must distinguish the established text extraction subset from broader document compatibility.
