### H3.4 Nearest plain letter when the font lacks a character (fix #4)

- `crates/lumen-text/Cargo.toml`: add `unicode-normalization = "0.1"`.
- `lumen-text/src/lib.rs`: add the following.
  ```rust
  /// Characters the font lacks become their plain base letter (ṇ → n, ñ → n) when the font has it.
  pub fn fold_unsupported(text: &str, covers: impl Fn(char) -> bool) -> Cow<'_, str>
  ```
  For each char, in this order:
  1. Keep it if `covers(c)`, or if it is a format character (U+200B-U+200F, U+2060, U+FEFF), because the shaper hides those and ZWNJ changes Indic shaping.
  2. Map `'\u{A836}'` to `'\u{0AF0}'` (`૰`) when the face covers that.
  3. Otherwise decompose the char (NFD) and drop the combining marks (`unicode_normalization::char::is_combining_mark`). If what is left is non-empty and every char of it is covered, use it.
  4. Otherwise keep the original char. Fallback or a box is the last resort.

  Return `Cow::Borrowed` when nothing changed, which is the common case.
- Coverage: `TextRenderer` keeps `HashMap<String, HashSet<u32>>` (family → codepoints), built once per family from the regular face's charmap with `cosmic_text::skrifa` (the same lookup `measured_gujarati_scale` does at line 381). Add the comment `// shortcut: bold/italic faces are assumed to cover what the regular face covers; check them if a font family is uneven.`
- `styled_runs` (line 493): treat U+A830-U+A83F (North Indic number forms) as Gujarati, so `꠶` lands in the Gujarati run where `૰` exists. In `layout_at` (line 323), fold each run's text with its own family's coverage before `set_rich_text`. The runs become owned `Cow`s, so adjust the lifetimes; don't add a struct.
- egui labels (book lists, search snippets, unit titles) use the UI's own Poppins copy (`lumen-app/assets/fonts/Poppins-Regular.ttf`, same coverage as lumen-text's copy, checked). Add `pub fn poppins_covers(ch: char) -> bool` in lumen-text (a `OnceLock<HashSet<u32>>` from the embedded `POPPINS_REGULAR`), and apply `fold_unsupported(text, lumen_text::poppins_covers)` in the plain egui branches of `gu_label` and `gu_selectable` (`lumen-app/src/text.rs:178-197`). The shaped branch already folds inside the renderer.
- Tests (lumen-text): ṇ → n, Ṛ → R, ñ → n with a coverage that lacks ñ, ā kept when covered, ā → a when not, Gujarati unchanged, ZWNJ unchanged, `꠶` → `૰`, and an all-covered input returns `Borrowed`. Add one renderer test: shaping "Kṛṣṇa" with the default faces gives glyphs that all come from Poppins, with no `.notdef` (glyph id 0).
- Commit: `fix(text): show the plain letter when a font lacks a diacritic`.
