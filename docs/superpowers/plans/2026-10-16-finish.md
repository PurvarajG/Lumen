## Definition of done (Lumen 1.0, macOS Apple Silicon)

In scope, verified by tests plus native checks:

- Interchange: plain text, OpenLyrics import/export, experimental ProPresenter 21.4 text import.
- Editing: positioned primary text box, inline rich text markup (bold/italic/underline/colour), extra slide objects (text/image/shape), fade transitions, undo/redo, autosave and crash recovery.
- Clocks: countdown, countdown-to-time, elapsed, overrun; persisted in the project; timers/messages UI.
- Layers: background media, slide, props, announcement message; cue actions for each.
- Media: media bin with image/video thumbnails, slide audio cues and an audio bin (pure-Rust decode, output device selection).
- Outputs: audience/stage on a chosen display, fullscreen, stage layout choices.
- Control: local HTTP JSON API with token, OSC input, MIDI note → macro.
- Scripture from user-supplied files (OSIS XML / plain verse-per-line), reference search, slide generation.
- Packaging: optimized release bundle, DMG, README/PARITY/STATUS current.

Gated or out of scope for 1.0 (documented in PARITY.md, not advertised): NDI/Syphon (adapter seam only), SDI, DMX, SMPTE timecode, recording/streaming, video capture input, cloud/team sync, licensed lyric/scripture services, notarization, Windows/Linux validation.

## Waves

Work runs in git worktrees `.local/wt/<task>` on branches `wave/<task>`, all sharing `CARGO_TARGET_DIR=<repo>/target` (bounded disk; cargo's lock serializes builds so memory stays bounded). Executors own only the files their brief names and commit on their branch. The orchestrator reviews the diff, runs fmt/test/clippy, merges into `development`.

- **Wave A (parallel, disjoint crates)**
  - A1 `lumen-interchange` crate — brief `docs/briefs/interchange.md` (+ addendum in `docs/briefs/a1-interchange.md`). Codex.
  - A2 `lumen-core` schema v2 — `docs/briefs/a2-core-v2.md`. Antigravity.
  - A3 `lumen-control` crate — `docs/briefs/a3-control.md`. Antigravity.
- **Wave B**
  - B1 app integration of A1–A3: import UI, timers/messages/props UI, undo/redo, autosave/recovery, fade rendering, rich text rendering, text box positioning. Codex (single app writer).
  - B2 `lumen-media` audio + thumbnails (parallel with B1, media crate only). Antigravity.
  - B3 `lumen-scripture` crate (parallel, new crate). Antigravity.
- **Wave C**
  - C1 app: media bin, audio bin, scripture panel, MIDI/OSC/HTTP wiring, display assignment, stage layouts, slide object editor.
  - C2 UI polish pass (impeccable + taste), with screenshots reviewed by the orchestrator.
- **Wave D** release profile, bundle/DMG script, docs, final verification, parity table update.

## Review gates

Each merge: `cargo fmt --all -- --check`, `cargo test --workspace`, `cargo clippy --workspace --all-targets -- -D warnings`. Wave B/C/D merges also launch the native app and inspect operator/audience/stage windows. STATUS.md is updated after each wave.
